AI Copilot

版本 0.4.8 · macOS（Apple Silicon / arm64）· 使用说明

这是什么

AI Copilot 是一款运行在本机的 macOS 桌面应用，把「批量处理文件」和「AI 智能体」结合：批量替换内容、改文件名、转格式（含 PDF 互转、保留格式）、PDF 去水印、按模版归类整理文件；内置 AI 智能体可对话式处理文件，并支持技能扩展——在线搜索/本地移植/预置技能，能力可持续增长。全部本地运行，只有调用你自己配置的 AI 接口时才联网。

大概功能

✦ AI 助手
用自然语言指挥智能体：扫描、读取、编写、修改、排版文件，看图、格式转换、执行终端命令、打开文件/网页。敏感操作先弹授权。侧边栏自动记录对话历史，可切换/改名/归档/删除。
🧩 智能体技能
AI 设置里管理技能：预置（格式转换/看图/终端命令）、在线搜 GitHub 技能一键下载安装、本地 Claude Code 源码包技能移植安装。装得越多，AI 越能干。
⇄ 按规则替换文件
选文件/文件夹 → 建「查找→替换」规则 → 选保存方式 → 批量替换内容。
✎ 文件名修改
选文件/文件夹 → 加规则 → 批量修改文件名。
⤨ 文件格式转换
doc/docx/rtf/odt/html/txt/md/json/csv/pdf 互转。保持目录结构、转 PDF 保留格式、AI 助手转换。
💧 PDF 去水印
选 PDF → 分析文字水印（含中文，可 AI 辅助）→ 勾选删除 → 输出。支持文字类水印。
⚡ 文件自动化
选模版 + 选文件 + 设规范 → AI 按模版编写；或点「转换」按模版结构原样归类复制（零改动）。
⚙ AI 设置
配置模型提供方（Anthropic / OpenAI / DeepSeek / MiniMax / Kimi / 智谱 / 通义 / 豆包 / 自定义），拉取模型、测试连接、保存（仅存本机）。

快速上手

  1. 安装：把 AI Copilot.app 拖到「应用程序 / Applications」。
  2. 配置模型：「AI 设置」→「新增配置」→ 选厂商、填地址与 Key → 「拉取模型」→ 选中 → 「保存」。
  3. 装技能（可选）：「AI 设置 → 智能体技能」在线搜或本地移植，给 AI 加能力。
  4. 开始使用：从左侧选功能模块，或直接在「AI 助手」里用自然语言下任务。

提示：首次打开若提示"无法验证开发者"，请到「系统设置 → 隐私与安全性」点"仍要打开"。使用语音输入会请求麦克风/语音识别权限。

搭建基础（技术架构）

基于 Electron + Node.js（arm64，原生 HTML/CSS/JS 界面）：

  • 主进程 main.js：窗口与 IPC、文件扫描/替换/重命名/格式转换（智能 PDF 引擎：LibreOffice/Pages/Numbers/textutil-html 自动选最佳）/PDF 去水印/归类转换、技能管理（列表/删除/本地扫描/GitHub 搜索与安装）、AI 配置/对话、权限模式。
  • 智能体 agent.js：类 Claude Code 架构——agent loop + 工具注册表（含 convert_file/view_image/run_command）+ 子代理 + 动态技能加载（内置 + userData/skills 外部技能）+ TodoWrite + 上下文压缩 + 权限闸门 + 消息清洗，双协议 Anthropic / OpenAI 兼容，支持视觉输入。
  • 专项引擎：office-replace.js（解包 Office/zip）、pdf-watermark.js（PDF 解析 + CID 中文提取）。
  • 配置存储：~/Library/Application Support/AI Copilot/（模型配置、自动化预设、技能）。

隐私与安全

  • 文件与数据全部保存在本机，不上传任何服务器。
  • API Key 仅存本机配置文件。
  • 联网仅在你调用 AI 接口或搜索/下载技能时发生。
  • 写文件 / 修改 / 批量替换 / 终端命令 / 打开文件或网页等敏感操作，默认都先请求授权。
